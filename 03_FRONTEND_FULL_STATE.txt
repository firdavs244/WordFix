3. API LAYER
================================================================

### api/client.ts — Axios instance
- baseURL: VITE_API_URL || "http://localhost:8000/api/v1"
- timeout: 30000ms
- Headers: Content-Type: application/json, Accept: application/json

Request Interceptor:
- JWT token → Authorization: Bearer {token}
- Token localStorage["access_token"] dan olinadi

Response Interceptor:
- 401 → Token refresh logikasi:
  - refresh_token bilan /auth/token/refresh/ ga so'rov
  - Yangi access_token → localStorage ga saqlash
  - Original request qayta yuborish
  - Queue mexanizmi (isRefreshing + failedQueue) — bir vaqtda ko'p 401 bo'lganda
  - Refresh fail → localStorage tozalash + /login ga redirect
- 403 → toast.error("Permission denied")
- 500 → toast.error("Server error")
- No response → toast.error("Network error")

5. STATE MANAGEMENT
================================================================

### 5.1 Zustand Stores (3 ta)

#### useAuthStore (89 qator)
State:
- user: User | null
- isAuthenticated: boolean
- isLoading: boolean (default: true)

Actions:
- setUser(user) → user, isAuthenticated, isLoading yangilash
- setLoading(loading) → isLoading yangilash
- login(credentials) → authApi.login → token saqlash → user set
- register(data) → authApi.register → token saqlash → user set
- googleLogin(credential) → authApi.googleLogin → token saqlash
- logout() → authApi.logout → localStorage tozalash → state reset
- fetchProfile() → authApi.getProfile → user set
- initialize() → localStorage["access_token"] tekshirish → fetchProfile()

Token saqlash: localStorage (access_token, refresh_token)

#### useAppStore (23 qator)
State:
- sidebarCollapsed: boolean (default: false)

Actions:
- toggleSidebar() → sidebarCollapsed toggle
- setSidebarCollapsed(collapsed) → to'g'ridan-to'g'ri set

#### useReviewStore (82 qator)
State:
- currentSession: ReviewSession | null
- words: Word[]
- currentIndex: number
- isFlipped: boolean
- answers: Map<string, ReviewQuality>

Actions:
- setSession(session) → session set
- setWords(words) → words set + reset index/flip/answers
- flipCard() → isFlipped toggle
- setFlipped(flipped) → to'g'ridan-to'g'ri set
- recordAnswer(wordId, quality) → answers Map ga qo'shish
- nextWord() → currentIndex++, isFlipped=false
- previousWord() → currentIndex--, isFlipped=false
- reset() → barcha state ni boshlang'ich holatga qaytarish

Computed:
- currentWord() → words[currentIndex]
- progress() → (answers.size / words.length) * 100
- isLastWord() → currentIndex >= words.length - 1
- totalAnswered() → answers.size
