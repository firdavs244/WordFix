1. ARXITEKTURA UMUMIY KO'RINISHI
================================================================================

WordFix backend Clean Architecture (Hexagonal Architecture) asosida qurilgan.
Har bir feature (words, users) 4 qatlamga bo'lingan:

┌────────────────────────────────────────────────────────────────────┐
│                    PRESENTATION LAYER                              │
│  (Views, Serializers, URLs, Dependencies)                         │
│  HTTP request → Serializer validation → Use Case chaqirish        │
├────────────────────────────────────────────────────────────────────┤
│                    APPLICATION LAYER                               │
│  (Use Cases / Business Logic)                                     │
│  Use Case = bitta biznes operatsiya (SRP)                        │
│  Repository interfeyslari orqali ishlaydi                        │
├────────────────────────────────────────────────────────────────────┤
│                    DOMAIN LAYER                                    │
│  (Entities, Value Objects, Domain Services, Repository Interfaces)│
│  Pure Python - Django'ga bog'liq EMAS                            │
│  SM-2 algoritm, Enrichment mapping, Combo system                 │
├────────────────────────────────────────────────────────────────────┤
│                    INFRASTRUCTURE LAYER                            │
│  (Django ORM Models, Repository Implementations, Celery Tasks)    │
│  Domain interfeyslari konkret implementatsiyasi                   │
└────────────────────────────────────────────────────────────────────┘

Dependency Injection: Presentation → Dependencies → Use Cases + Repositories
  - Har bir use case constructor injection orqali repository/service oladi
  - Factory pattern: get_add_word_use_case(), get_words_use_case() va hokazo

3. DEPENDENCY INJECTION PATTERN
================================================================================

Presentation layer'dagi har bir view use case'ni dependency factory orqali oladi.
Bu Clean Architecture'ning asosiy prinsipi - dependency inversion.

Misol: So'z qo'shish oqimi

# dependencies/word_deps.py
def get_add_word_use_case():
    repo = get_word_repository()         # → DjangoWordRepository()
    enrich_task = _get_enrich_task()     # → enrich_word_task.delay callable
    return AddWordUseCase(
        repository=repo,
        enrich_task=enrich_task,
        enrichment_enabled=True,
    )

# views/word_views.py
class WordListCreateView(APIView):
    def post(self, request):
        serializer = WordCreateSerializer(data=request.data)
        serializer.is_valid(raise_exception=True)
        use_case = get_add_word_use_case()  # ← DI bu yerda
        word = use_case.execute(user_id=request.user.id, data=serializer.validated_data)
        ...

# application/use_cases/word_crud.py
class AddWordUseCase:
    def __init__(self, repository, enrich_task=None, enrichment_enabled=True):
        self.repository = repository  # AbstractWordRepository interfeysi
        ...
    def execute(self, user_id, data):
        word = self.repository.create(user_id=user_id, **data)
        if self.enrichment_enabled and self.enrich_task:
            self.enrich_task(str(word.id), str(user_id))  # Celery'ga jo'natish
        return word

7. DATABASE MODELS XULOSA
================================================================================

Words app'da jami 12+ Django model mavjud:

ASOSIY:
  - Word (30+ maydon, 5 DB index, unique_together=[user, original_word])
  - WordCategory (user, name, color, icon)
  - WordDistractor (cached AI-generated distractors)

REVIEW:
  - ReviewSession (types: review/quick/focus/learn/mixed)
  - ReviewLog (har bir review answer)
  - DailyStreak (OneToOneField → User)
  - DailyActivity (unique_together=[user, date])

TEST:
  - TestSession
  - TestQuestion (6 question types)

GAME:
  - GameSession (7 game types)
  - StoryRound, ListeningRound, SynonymAntonymRound, IrregularVerbRound

CHAT:
  - ChatSession (M2M words_practiced)
  - ChatMessage

BOSHQA:
  - ConfusingPair (unique_together=[user, word_1, word_2])
  - DailyChallenge (unique_together=[user, date])
