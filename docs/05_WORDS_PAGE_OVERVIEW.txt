1. SAHIFA HAQIDA
================================================================================
Words sahifasi - bu WordFix ilovasining markaziy sahifasi bo'lib, foydalanuvchi
o'z lug'at bazasini (Word Bank) boshqaradi. Bu yerda so'zlar qo'shiladi,
tahrirlanadi, o'chiriladi, arxivlanadi va AI orqali boyitiladi (enrichment).

URL: http://localhost:5173/words
Route: /words → WordsPage component (lazy-loaded)
Himoyalangan: Ha (ProtectedRoute - faqat autentifikatsiya qilingan foydalanuvchilar)
Layout: RootLayout ichida (sidebar + header bilan)

3. ASOSIY FUNKSIYALAR
================================================================================

3.1 So'z qo'shish (Add Word)
    - "Add Word" tugmasi → AddWordModal ochiladi
    - AddWordForm: original_word, translation, definition, example, difficulty, notes
    - Saqlanganda: POST /api/v1/words/ → auto-enrichment trigger → XP + badge check

3.2 So'zlarni ko'rish (List Words)
    - GET /api/v1/words/?page=X&page_size=20&ordering=-created_at
    - Grid (3 ustun) yoki List ko'rinishda
    - Har bir karta: so'z, tarjima, ta'rif, confidence bar, badges

3.3 Qidirish va Filtrlash
    - Search: so'z yoki tarjima bo'yicha qidirish
    - Difficulty filter: Easy / Medium / Hard
    - Sahifalash: 20 so'z per page

3.4 So'z tafsilotlari (Word Detail Modal)
    - Kartani bosganda WordDetailModal ochiladi (303 qatorli component)
    - Ko'rsatiladi: definition, example, mnemonic, usage_notes,
      synonyms, antonyms, collocations, word_family,
      review stats, confidence bar, SM-2 info
    - Actions: Archive, Enrich, Delete

3.5 So'zni o'chirish (Delete)
    - Confirm dialog → DELETE /api/v1/words/{id}/
    - Cache invalidation, stats yangilanish

3.6 So'zni arxivlash (Archive)
    - POST /api/v1/words/{id}/archive/ → so'z arxivga o'tadi
    - Arxiv tabi: ArchivedWordsSection (undo imkoniyati bilan)

3.7 AI Enrichment
    - Yakka: POST /api/v1/words/{id}/enrich/
    - Hammasi: POST /api/v1/words/enrich-all/
    - Celery task orqali asinxron ishlaydi
    - AI to'ldiradi: tarjima, ta'rif, misol, mnemonik, synonyms, antonyms...

3.8 Archived Tab
    - ArchivedWordsSection: arxivlangan so'zlar ro'yxati
    - Search, grid, pagination, bulk unarchive


4. STATE MANAGEMENT
================================================================================

React Query (TanStack Query) ishlatiladi:
- Query Keys factory pattern: wordKeys.all, wordKeys.list(filters), wordKeys.stats()
- Mutations: create/update/delete/archive/enrich → automatic cache invalidation
- Toast notifications: sonner kutubxonasi orqali success/error xabarlar
