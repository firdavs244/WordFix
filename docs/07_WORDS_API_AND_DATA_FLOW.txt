10. DATA FLOW DIAGRAMMALARI
================================================================================

10.1 SO'Z QO'SHISH OQIMI:
─────────────────────────
Frontend (AddWordForm)
    │
    ▼
POST /api/v1/words/
    │
    ▼
WordListCreateView.post()
    │
    ├── WordCreateSerializer.is_valid()  ← Validation
    │
    ├── get_add_word_use_case()          ← Dependency Injection
    │
    ▼
AddWordUseCase.execute()
    │
    ├── DjangoWordRepository.create()    ← DB yozish
    │       │
    │       ├── unique_together tekshirish (user + original_word)
    │       ├── Word.objects.create()
    │       └── Cache invalidation
    │
    ├── enrich_word_task.delay()         ← Celery'ga jo'natish (async)
    │       │
    │       ▼  (Background)
    │   EnrichWordUseCase.execute()
    │       ├── AI Provider → generate_json(prompt)
    │       ├── WordEnrichmentDomainService.enrich_word()
    │       ├── TTS Provider → generate_audio()
    │       ├── word_repo.update() (enriched data saqlash)
    │       └── generate_distractors_task.delay()
    │
    ├── _award_xp(user_id, "word_added")     ← XP berish
    ├── _increment_progress(words_learned=1)  ← Progress yangilash
    ├── _check_badges(user_id)                ← Badge tekshirish
    └── UpdateChallengeProgressUseCase        ← Daily challenge progress
    │
    ▼
Response: { success: true, data: {word + xp_earned + new_badges}, status: 201 }
    │
    ▼
Frontend: React Query cache invalidation → wordKeys.lists(), wordKeys.stats()
    │
    ▼
UI yangilanadi: yangi so'z ro'yxatda paydo bo'ladi + toast notification


10.2 SO'ZLAR RO'YXATINI OLISH OQIMI:
──────────────────────────────────────
Frontend (WordsPage loads)
    │
    ├── useWords(filters) hook
    │       │
    │       ▼
    │   wordsApi.list(filters)
    │       │
    │       ▼
    │   GET /api/v1/words/?page=1&page_size=20&ordering=-created_at&search=...
    │
    └── useWordStats() hook
            │
            ▼
        GET /api/v1/words/stats/

Backend:
    WordListCreateView.get()
        │
        ├── Query params → filters dict
        ├── get_words_use_case() 
        ├── GetWordsUseCase.execute()
        │       │
        │       ▼
        │   DjangoWordRepository.get_all_by_user()
        │       ├── Filter: category, difficulty, is_mastered, part_of_speech, search
        │       ├── Ordering: created_at, original_word, confidence_score
        │       ├── Pagination: (page-1)*page_size : page*page_size
        │       └── Return: (list[WordEntity], total_count)
        │
        ▼
    Response: {
        success: true,
        data: [...words],
        meta: { page, total_pages, total_count, page_size }
    }


10.3 ENRICHMENT OQIMI:
───────────────────────
POST /api/v1/words/{id}/enrich/
    │
    ▼
EnrichWordView.post()
    │
    ├── word_repo.get_by_id()  ← So'z mavjudligini tekshirish
    ├── enrich_word_task.delay(word_id, user_id)  ← Celery'ga
    │
    ▼ (Celery worker - asinxron)
enrich_word_task()
    │
    ├── get_enrich_use_case()  ← DI
    ▼
EnrichWordUseCase.execute()
    │
    ├── word_repo.get_by_id()
    ├── user_repo.get_user_language_info()  ← Foydalanuvchi tili
    ├── ai_provider.is_available()
    ├── word_repo.update(enrichment_status="enriching")
    │
    ├── ai_provider.generate_json(prompt)   ← AI chaqirish
    │   Prompt ichida: native_language, proficiency_level, word
    │   AI javob: {
    │       translation, pronunciation, part_of_speech,
    │       definition, example_sentence, example_translation,
    │       synonyms[], antonyms[], collocations[], word_family[],
    │       difficulty_level, mnemonic, usage_notes
    │   }
    │
    ├── WordEnrichmentDomainService.enrich_word()  ← Domain mapping
    │
    ├── tts_provider.generate_audio()       ← TTS audio
    │   → media/audio/words/{user_id}/{word_id}/pronunciation.mp3
    │
    ├── word_repo.update(enriched fields)   ← DB yangilash
    │
    └── generate_distractors_task.delay()   ← Distractor yaratish
        │
        ▼
    Smart distractors (AI-based)
        → WordDistractor model'ga saqlash

11. RESPONSE FORMAT
================================================================================

Barcha API response'lar yagona formatda:

{
    "success": true/false,
    "data": { ... },          // Asosiy ma'lumot
    "message": "Success",     // Xabar
    "errors": null,           // Xatolar (agar bo'lsa)
    "meta": {                 // Sahifalash (agar kerak bo'lsa)
        "page": 1,
        "total_pages": 8,
        "total_count": 150,
        "page_size": 20
    }
}


12. FRONTEND → BACKEND INTEGRATSIYA
================================================================================

Frontend API client: src/api/client.ts
  - Axios instance
  - Base URL: VITE_API_URL (environment variable)
  - JWT Authentication: Authorization: Bearer {access_token}
  - Automatic token refresh interceptor (401 → refresh → retry)

Feature API: src/features/words/api/wordApi.ts
  - 19 metod (list, getById, create, update, delete, bulkCreate, getStats, 
    getReviewWords, listCategories, createCategory, deleteCategory,
    archiveWord, unarchiveWord, getArchivedWords, bulkArchiveWords,
    enrichWord, enrichAll)

React Query hooks: src/features/words/hooks/useWords.ts
  - Query key factory: wordKeys.all → wordKeys.lists() → wordKeys.list(filters)
  - 6 query hooks: useWords, useWord, useWordStats, useReviewWords, useCategories, useArchivedWords
  - 11 mutation hooks: useCreateWord, useUpdateWord, useDeleteWord, useBulkCreateWords,
    useCreateCategory, useDeleteCategory, useArchiveWord, useUnarchiveWord,
    useBulkArchive, useEnrichWord, useEnrichAll
  - Har bir mutation → automatic cache invalidation + toast notification
