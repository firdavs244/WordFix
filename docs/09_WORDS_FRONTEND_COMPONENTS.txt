8. ANIMATION VA TRANSITION'LAR
================================================================================

Framer Motion kutubxonasi keng ishlatiladi:

PageTransition:
  - Sahifa yuklanganda fade-in + slide-up
  - initial={{ opacity: 0, y: 20 }}
  - animate={{ opacity: 1, y: 0 }}

listContainerVariants (so'zlar ro'yxati):
  - Stagger children: har bir karta ketma-ket paydo bo'ladi
  - Container: hidden → show

listItemVariants (har bir karta):
  - hidden: { opacity: 0, y: 20 }
  - show: { opacity: 1, y: 0 }

cardHoverVariants (karta ustiga kelganda):
  - rest: { scale: 1 }
  - hover: { scale: 1.02, y: -2 }
  - tap: { scale: 0.98 }

AnimatePresence:
  - Modal ochilish/yopilish animatsiyasi
  - Exit animatsiyasi (so'z o'chirilganda karta yo'qoladi)

Segmented Control:
  - layoutId orqali spring animation
  - Tab o'tishda smooth slider effekti


9. REACT QUERY HOOKS BATAFSIL
================================================================================

Fayl: src/features/words/hooks/useWords.ts

QUERY KEY FACTORY:
  wordKeys = {
    all: ['words'],
    lists: () => ['words', 'list'],
    list: (filters) => ['words', 'list', filters],
    details: () => ['words', 'detail'],
    detail: (id) => ['words', 'detail', id],
    stats: () => ['words', 'stats'],
    review: () => ['words', 'review'],
    categories: () => ['words', 'categories'],
    archived: () => ['words', 'archived'],
  }

QUERY HOOKS:
  ┌──────────────────┬──────────────────────────────────┬─────────────────────┐
  │ Hook             │ API Call                         │ Query Key            │
  ├──────────────────┼──────────────────────────────────┼─────────────────────┤
  │ useWords         │ wordsApi.list(filters)           │ wordKeys.list(f)    │
  │ useWord          │ wordsApi.getById(id)             │ wordKeys.detail(id) │
  │ useWordStats     │ wordsApi.getStats()              │ wordKeys.stats()    │
  │ useReviewWords   │ wordsApi.getReviewWords()        │ wordKeys.review()   │
  │ useCategories    │ wordsApi.listCategories()        │ wordKeys.categories │
  │ useArchivedWords │ wordsApi.getArchivedWords(params)│ wordKeys.archived() │
  └──────────────────┴──────────────────────────────────┴─────────────────────┘

MUTATION HOOKS (Cache Invalidation):
  ┌────────────────────┬─────────────────────────────────────────────────────┐
  │ Hook               │ Invalidates                                        │
  ├────────────────────┼─────────────────────────────────────────────────────┤
  │ useCreateWord      │ lists() + stats() + ['daily-challenges']           │
  │ useUpdateWord      │ all (barcha word queries)                          │
  │ useDeleteWord      │ lists() + stats()                                  │
  │ useBulkCreateWords │ lists() + stats()                                  │
  │ useCreateCategory  │ categories()                                       │
  │ useDeleteCategory  │ categories() + lists()                             │
  │ useArchiveWord     │ lists() + stats() + archived()                     │
  │ useUnarchiveWord   │ lists() + stats() + archived()                     │
  │ useBulkArchive     │ lists() + stats() + archived()                     │
  │ useEnrichWord      │ all                                                │
  │ useEnrichAll       │ all                                                │
  └────────────────────┴─────────────────────────────────────────────────────┘

TOAST NOTIFICATIONS (Sonner):
  - Success: "Word added successfully!", "Word deleted.", "Enrichment started."
  - Error: "Failed to add word.", "Failed to delete word.", etc.
